Overview — Key Findings

Dataset: CDC Behavioral Risk Factor Surveillance System (BRFSS) 2024, n = 457,670 respondents, 49 states + DC + territories. Outcome: Ever diagnosed with diabetes (binary). Method: Multiple logistic regression.
